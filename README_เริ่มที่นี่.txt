ชุดโปรเจกต์ app4 — ระบบพยากรณ์การใช้ไฟฟ้า 19 จังหวัด

ไฟล์ที่ใช้เปิดโปรแกรม
1. streamlit_app.py          หน้าจอโปรแกรม
2. forecasting_engine.py    โมเดล Train และ Forecast
3. Dataset.xlsx             Dataset หลักที่โปรแกรมเปิดอัตโนมัติ
4. images/                  ภาพที่หน้าโปรแกรมเรียกใช้

วิธีเปิดโปรแกรม
วิธีที่แนะนำ: ดับเบิลคลิกไฟล์ "เปิดโปรแกรม_ธีมมืด.command"

หรือเปิด Terminal แล้วใช้คำสั่ง
cd /Users/mac/Desktop/app4
./เปิดโปรแกรม_ธีมมืด.command

ไฟล์เปิดโปรแกรมจะกำหนด Dark theme ตั้งแต่เริ่มเซิร์ฟเวอร์ เพื่อให้ DataFrame
และ Data Editor ทุกหน้าเป็นพื้นเข้ม ไม่ย้อนกลับเป็นสีขาว

ไฟล์ตรวจค่าจริงปี 2026
- ข้อมูลจริง_สำหรับตรวจสอบ/Actual_Load_2026_1.xlsx ถึง Actual_Load_2026_6.xlsx
- ใช้อัปโหลดในหน้า Accuracy Check ไม่ใช่ข้อมูลที่ให้โมเดลเห็นล่วงหน้า

ไฟล์สำหรับนำเสนออาจารย์
- เอกสารสำหรับสอบ/สรุปงานวิจัยและผลพยากรณ์_สำหรับนำเสนอสอบ.docx
- เอกสารสำหรับสอบ/สรุปงานวิจัยและผลพยากรณ์_สำหรับนำเสนอสอบ.pdf
- ผลทดลอง/ชุดข้อมูลและผลทดลองปัจจัยปฏิทิน_19จังหวัด_มค-มิย2026.xlsx

ภายในไฟล์ผลทดลองมี 5 ชุดข้อมูล
- Baseline
- Calendar
- EUI/SEU
- PEA/MEA/EGAT
- All Factors

หมายเหตุสำคัญ
- โปรแกรมหลักใช้ Dataset.xlsx ที่อยู่โฟลเดอร์เดียวกับ streamlit_app.py
- อย่าเปลี่ยนชื่อ forecasting_engine.py หรือ Dataset.xlsx
- ผลทดลองเป็นการเปรียบเทียบปัจจัยด้วย Walk-forward 19 จังหวัด เดือน ม.ค.–มิ.ย. 2026
- ปฏิทินช่วย MAPE รวมประมาณ 3.90% แต่ควรเลือกใช้รายจังหวัด ไม่ควรบังคับทุกจังหวัด
